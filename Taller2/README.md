Este cuaderno contiene del Taller 2 del curso, correspondiente al análisis de 16 canales de datos neuronales a la figura, enfocado en el procesamiento de señales electrofisiológicas multicanal, detección de potenciales de acción (spike sorting), clustering mediante K-means y control de calidad (bombcell) para la identificación y evaluación funcional de unidades neuronales. Los datos de prueba (taller2_limpia.h5 y taller2_ruidosa.h5) no se incluyen en el repositorio debido a su tamaño binario; son descargados e importados automáticamente mediante el script de preparación inicial desde la carpeta compartida en Google Drive (ID: 1L4t2SJW36ntvtpDvW3wQEUDLRLehXVGv).
